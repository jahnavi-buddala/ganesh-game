# SUBWAY-SURFERS

SUBWAY-SURFERS made with Three.js (from [DanielLin0516/SUBWAY-SURFERS](https://github.com/DanielLin0516/SUBWAY-SURFERS.git)).

## Features:

- Infinite procedural subway map
- Collision front, sides, and top (running on train roofs)
- Full 3D skinned character model with animations (Run, Jump, Roll, Fall, Lookback)
- Subway trains, hurdles, roadblocks, slopes, coins
- Score, coin collection, and mistake tracking
- Support PC and keyboard play
- Restart game on collision

## Controls:
- **P**: Start Game
- **A / D** or **Left / Right Arrow**: Switch lanes
- **Space / Up Arrow**: Jump
- **S / Down Arrow**: Roll / Slide
- **R**: Restart game
